# Organizations Data Rights Extension

This BunkFy composition extension adapts GMA Organizations' product-neutral
scope lifecycle to BunkFy's tenant-termination owner contract. It owns no
database and contains no generic Organizations behavior.

The executable [personal-data catalogue](personal-data-catalog.v1.json)
classifies the five typed portability streams. The deterministic
[resolved inventory](personal-data-inventory.v1.md) is generated with
`BunkFy.DataGovernance.Tool`.

Token digests and transport journals are not portable records. GMA
Organizations owns their destruction and returns only bounded progress and a
payload-free terminal proof.
